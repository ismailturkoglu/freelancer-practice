# Portfolio

This is a multi-page personal portfolio project built using HTML, CSS (SCSS) and basic JavaScript. The goal of this project is to practice responsive web design, SCSS structure, and basic frontend interactions.

## Live Demo
https://ismailturkoglu.github.io/freelancer-practice/

## Features
- Multi-page structure (Home, About, Projects, Contact)
- Responsive design for mobile and desktop
- SCSS-based styling architecture
- Basic JavaScript interactions (typewriter effect, carousel, form input formatting)
- Contact form integration (Formspree)
- Image lightbox and carousel integration

## Technologies Used
- HTML5
- CSS3 / SCSS
- JavaScript (Vanilla JS)
- Owl Carousel
- GLightbox
- Font Awesome

## Pages
- Home: Introduction and skills overview
- About: Personal profile and skill progress bars
- Projects: Image gallery with lightbox interaction
- Contact: Contact form with input validation

## What I Learned
- Building multi-page website structure
- SCSS organization and responsive design
- Integrating third-party libraries
- Basic JavaScript DOM manipulation
- Form handling and input formatting

## Contact
This project includes a working contact form powered by Formspree.
